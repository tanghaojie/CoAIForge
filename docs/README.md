# 项目文档入口

文档按单项目管理，先确认实际能力和任务范围，不遍历整个目录。

1. 查看[活动计划](plans/active/README.md)，避免重复实施。
2. 从[现行设计](design/README.md)选择相关规范和模块。
3. 需要长期取舍时查看[有效决策](decisions/README.md)。
4. 实施与验证参考[操作指南](guides/README.md)及[参考资料](reference/README.md)。
5. 新文档使用[公共模板](templates/README.md)。历史查证才进入[归档索引](archive/README.md)。

模板维护过程的计划、日志、历史证据不作为生成项目历史复制。
